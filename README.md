# Wi-Fi RSSI Fall Detection System

Upload-only Official Testing Result Explorer with the same Streamlit dashboard template.

## Behaviour

- The dashboard no longer has a typed filename input.
- Users upload a `.mat` testing file.
- The backend uses the uploaded filename to search `transform_comparison_predictions_by_file.csv` generated by the Evaluation script.
- The backend reads the uploaded raw `.mat` file and extracts the envelope signal preview using the same preprocessing logic as `Feature_Extractions.m`.
- Official testing is not recomputed in the dashboard.

## Local run

### FastAPI

```bat
cd fastapi_backend
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Streamlit

```bat
cd streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

Open: http://localhost:8501


## Saved Testing Data Picker

The backend can include only the testing `.mat` files under `fastapi_backend/data/sample_testing_data`. The Streamlit input panel lets users select one saved testing file, load its official outer-test result, and display its envelope preview without manually uploading a file.
